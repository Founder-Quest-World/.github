# Founder Quest World

Entrepreneurship programs for children and young people, from the first lemonade stand to
the first real customer.

Participants learn the way founders do: find a problem worth solving, come up with an idea,
build a prototype, talk to real customers, and work out the business, the marketing and the
money. Along the way they also ask who the idea helps.

## Programs

| Program | Ages | Status |
|---|---|---|
| **Mini Founders** | 8–13 | Running |
| **Youth Founders** | 13–20 | In development |

The course material is in Swedish.
